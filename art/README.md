# art/

Your work files: Blender `.blend` files in `blender/`, full-size textures (and their licences) in `textures/`.

Godot ignores this whole folder (that's what the hidden `.gdignore` file does). The game loads the exported `.glb` files in `assets/models/` instead. Guide: [docs/BLENDER.md](../docs/BLENDER.md).
